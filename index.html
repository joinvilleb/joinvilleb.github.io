Process

How I work

Start with scope

I audit what exists, talk to the actual users, and define the smallest version that solves the real problem before touching any code.

Build and ship

I move fast, keep the code readable, and prioritize shipping something real over over-engineering something perfect.

Own the outcome

I stay available after delivery, track what matters, and keep iterating when the numbers say something is off.
